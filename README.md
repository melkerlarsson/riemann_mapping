# Proof of the Riemann Mapping Theorem
Rigorous proof of the Riemann mapping theorem, for which you need only have read a basic course in complex analysis to understand. The document also contains proofs of many lemmas which are interesting theorems in their own rights. These include *The maximum principle* and the theory of *Normal families* and a strong charachterization of them using *uniformly bounded families*. A short background discussing the importance of the theorem, with the connection to the existence of a solution to the stationary heat equation, is included.
